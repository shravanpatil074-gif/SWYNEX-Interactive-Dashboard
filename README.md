# SWYNEX Technologies - Task 3: Interactive Dashboard

## Tool
Microsoft Power BI

## Project
Titanic Survival Analysis Dashboard

This project converts the cleaned Titanic dataset from Tasks 1 and 2 into an interactive BI dashboard.

## Included
- `data/cleaned_titanic_dashboard.csv` - dashboard-ready dataset
- `powerbi/DAX_Measures.txt` - measures to create in Power BI
- `powerbi/POWER_BI_SETUP.md` - exact setup steps
- `powerbi/DASHBOARD_LAYOUT.md` - visual and slicer specification
- `reports/dashboard_kpis.csv` - KPI values
- `reports/dashboard_insights.md` - key findings
- `dashboard_preview/dashboard_preview.html` - browser preview of the main visuals
- `dashboard_preview/*.png` - static chart previews

## Dashboard requirements covered
### KPIs
- Total Passengers
- Survivors
- Survival Rate
- Average Age
- Average Fare

### Charts
- Survival Rate by Gender
- Survival Rate by Passenger Class
- Passenger Distribution by Class
- Survival Rate by Age Group
- Survival Rate by Embarkation
- Survival Rate by Family Size

### Interactive filters
- Sex
- Pclass
- Embarked
- Age_Group

## Final Power BI file
Open Power BI Desktop, follow `powerbi/POWER_BI_SETUP.md`, and save the completed dashboard as `SWYNEX_Interactive_Dashboard.pbix`. Add that PBIX file to this repository after creating it.

## Important
The dashboard presents descriptive patterns from the Titanic dataset. It does not establish causation.
